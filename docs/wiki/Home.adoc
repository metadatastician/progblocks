== Canonical-source rule

`docs/wiki/` is canonical. The GitHub wiki for this repository currently
holds a single 32-byte stub `Home.md` — it is at most a future mirror of
this tree and must never be treated as an independent source of truth.
If the two ever disagree, `docs/wiki/` wins.

== Current state — read this first

[IMPORTANT]
====
ProgBlocks is **pre-alpha**. Nothing has been released. Version numbers
disagree across the repo (`package.k9`/`contracts.ncl` say `1.0.0`;
`progblocks.launcher.a2ml`/`progblocks-launcher.sh` say `0.1.0`;
`package.json` says `0.3.0`). Treat every version string as unreliable
and treat the component itself as experimental.

`src/prog-block.js` previously carried a fatal named-import mismatch
(`import { validateK9 }` from a module that exports only
`K9Validator` and `defaultValidator`) — a link-time `SyntaxError` that
kept the module graph from ever finishing loading, so the
`prog-block` custom element never registered and every `<prog-block>`
on a page using the `src/` tree was inert. That was fixed, and since
2026-10-05 `src/prog-block.js` imports nothing at all;
`tests/registration.test.js` asserts `customElements.get('prog-block')`
is defined so this class of bug cannot regress silently.

On 2026-10-05 the component was rewritten (branch
`feat/render-core-variants-vars`): it renders all text through
`textContent` (closing the former XSS surface), keeps focus while you
type, resolves its stylesheet against its own module URL, and follows
the WAI-ARIA tabs pattern. Its behaviour is unit-tested under happy-dom
(`bun test`, 27 tests); it has **not** been verified in a real browser,
with a screen reader, or by an automated accessibility audit.
====

See link:users/Feature-Status.adoc[Feature Status] for a full,
evidence-based table of what actually works.

== ProgBlocks in one paragraph

ProgBlocks is a dependency-free web component (`<prog-block>`) for
variant-aware, personalisable code examples in technical documentation
and wikis: variant tabs (e.g. OS or shell flavours of a command), kept in
step across blocks with `group`, `{{ variable }}` substitution with
optional inline defaults, and Copy and Download buttons for the personalised
text. It is not an editor, linter or data converter — the inline editor,
placeholder linter, split view, smart paste and JSON/CSV/Nickel export were removed
on 2026-10-05. It was conceived for BerryWiki
(`metadatastician/berrywiki`) and decoupled by design so it can be
dropped into other static sites — see
link:users/Getting-Started.adoc[Getting Started].
