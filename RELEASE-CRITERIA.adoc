Nothing defined "v1" before this document. ProgBlocks is pre-alpha at `0.3.0`,
with no tag and no published package. Every criterion below names the evidence
that satisfies it, so each one is a check that can fail. A criterion is *met*
only by evidence produced at the candidate commit or after it; it is *waived*
only by a recorded owner ruling. Numbers marked _(proposed)_ are the owner's to
set.

Independence is a standing condition, not a criterion: ProgBlocks must never
require BerryWiki or any other consumer.

== S: security and adversarial robustness

[cols="1,4,4,1", options="header"]
|===
| ID | Criterion | Evidence that satisfies it | Now

| S1 | A short threat model covers every surface: authored template text, `{{variable}}` substitution, attributes, `localStorage` and `storage` events, the download filename. | A section in `ARCHITECTURE.md`, or its own file. | ✅ `ARCHITECTURE.md` § Threat model; it records S4 and S5 as still open
| S2 | Hostile authored content stays inert in real browsers. | A real-browser test (R1) that injects markup and handlers through templates, variant labels, variable names and values, and asserts no element and no execution; with a planted negative that uses `innerHTML` and is caught. | 🟡 happy-dom only
| S3 | Rendering time grows linearly with input size. | `VAR_PATTERN` rewritten without overlapping quantifiers. A scaling test over generated adversarial inputs (including `{{a=` followed by spaces and no closing braces, deep nesting of braces, and many variables) at 16 KiB and 64 KiB: the 64 KiB case takes no more than _(proposed)_ 6× the 16 KiB case (linear growth allows about 4×), and every input up to 64 KiB renders within _(proposed)_ 250 ms in CI. | ✅ new `VAR_PATTERN`; four scaling tests in `tests/component.test.js` ("rendering time grows linearly"). Planted negative: with the old pattern restored the same tests did not finish in 200 s. The 250 ms bound applies when `CI` is set; locally it is 2500 ms, because a loaded workstation swings timings 3×
| S4 | Downloaded filenames cannot spoof. | Sanitisation of control and bidi characters (for example U+202E), leading dots, reserved names (such as `CON`) and length, each with a test. | ✅ `safeFilename()`; one test per class under "downloaded filenames cannot spoof". Planted negatives: removing each control fails its test
| S5 | A hostile same-origin `storage` event cannot inject state. | Tests for hostile `group` and `persist` values arriving through the event. | ✅ tests under "a hostile storage event cannot inject state": hostile names, group keys, `sessionStorage` events, and a hostile remembered value. Planted negative: dropping the `storageArea` check fails
| S6 | Parsing and rendering are property-tested. | Generated inputs over `tokenize` and rendering, asserting round-trip text and no element creation. | ❌
|===

== T: tests and gates that can fail

[cols="1,4,4,1", options="header"]
|===
| ID | Criterion | Evidence that satisfies it | Now

| T1 | Every gate has a planted negative in CI. | The axe audit, `run-probes.sh` (run with `--strict`), the JCS check and the pins check each shown to reject a known-bad input. | ❌
| T2 | Nothing pretends to validate. | `src/k9-validator.js` (DEBT C10, always "valid") is implemented or deleted, and `contracts.ncl` (T4) validates something outside itself or is removed. | ❌
| T3 | The suite catches real defects. | Mutation testing with a tool that runs under Bun (choice open), with a caught rate of at least _(proposed)_ 85%; surviving mutants are killed or justified. | ❌
|===

== P: packaging and the public contract

[cols="1,4,4,1", options="header"]
|===
| ID | Criterion | Evidence that satisfies it | Now

| P1 | There is a way to obtain a release, by both routes. | Owner ruling 2026-10-05: *both* a package registry and git tags. Evidence: a signed git tag with a GitHub release carrying the artefact, `SHA256SUMS` and its signature; *and* the same version published to the npm registry (consumed through `bunx` and Bun) with provenance attestation; `package.json` no longer `private` (DEBT CI3). Both routes must serve byte-identical files. | ❌
| P2 | The public API is frozen and documented. | A reference for every attribute, event, method and CSS custom property, marked as the v1 contract, with a test that fails if any of them changes undocumented. | ❌
| P3 | A versioning policy is published. | A SemVer statement saying what counts as breaking. | ❌
|===
