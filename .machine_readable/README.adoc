= .machine_readable Pillar

Agent-facing metadata for ProgBlocks.

== Contents

* `descriptiles/progblocks_chora.deed` — the repo deed: the single
  machine-readable record of this repository. Since 2026-10-05 (A2ML
  retired estate-wide) it carries what used to be separate `.a2ml` files
  as clauses: `(manifest …)` (was `0-AI-MANIFEST`), `(identity …)`
  (the grammar-required v5 `:repo-uuid` and its UUID v8 profile C twin,
  ADR-008), `(clade …)`, `(meta …)`, `(ecosystem …)`, `(agentic …)`, `(neurosym …)`,
  `(playbook …)`, `(anchor …)`, `(maturity …)` (was `STATE`), `(ply …)`
  (the `.github` directory manifests) and `(rsr-profile …)` — this repo's
  declared RSR v2.0 capability profile (deliberately minimal: `web-ui` and
  `library` only).
* `contractiles/<verb>/<verb>.ncl` — Must / Trust / Intend / Adjust / Dust /
  Bust probes, as Nickel data. Every `run` field is a plain shell one-liner,
  executable from the repository root; `tools/run-probes.sh` reads them via
  `nickel export` and runs them.
* `archive/state-v1.txt` — the retired STATE v1 journal, kept for the
  record. It is not current state.

== Canonical Read Order

1. `descriptiles/progblocks_chora.deed` — start with its `(manifest …)`
   clause, the universal entry point.
2. Its `(maturity …)` clause and `/DEBT.adoc` — where things ARE now,
   brutally honestly.
3. Its `(anchor …)` clause — what supersedes what when README.md and the
   verified facts disagree.
4. Its `(agentic …)` clause — what an agent may and may not do here.
5. The other clauses and `contractiles/`, as needed.

This repository is pre-alpha. Read `/EXPLAINME.adoc` (every claim mapped
to the code and test that evidence it) before repeating any claim from
`README.md`.
